# Sistema de Gerenciamento de Café

Sistema web desenvolvido com **Java e Spring Boot** para gerenciamento de um café.

O projeto permite cadastrar e consultar informações de clientes e produtos, utilizando uma API REST integrada a banco de dados.

## Tecnologias

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL
* HTML
* CSS
* JavaScript

## Funcionalidades

* Cadastro de produtos
* Consulta de produtos
* Cadastro e consulta de clientes
* Integração com banco de dados
* API REST
* Interface web para interação com o sistema

## Acesso

## Objetivo

Projeto desenvolvido para praticar desenvolvimento de aplicações web utilizando **Java, Spring Boot, APIs REST, JPA/Hibernate e banco de dados MySQL**.
